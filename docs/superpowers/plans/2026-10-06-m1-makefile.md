# M1 — Makefile for the Local Stack

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the usual local tasks with one short command: `make setup`, `make up`,
`make down`, `make test`, `make lint` and `make fresh`. Fix the known small problems
from the review of the local stack PR.

**Architecture:** A `Makefile` in the repository root calls Docker Compose. The commands
of the app run inside the `app` container. The `Makefile` exports the UID and GID of the
host user, so Compose builds the image with the correct user.

**Tech Stack:** GNU Make, Docker Compose 2.32.

**Spec:** `docs/superpowers/plans/milestones.md` (M1).

## Global Constraints

- Bash does not export `UID` and `GID`. The `Makefile` sets them with `id -u` and
  `id -g` and exports them to all commands.
- `make lint` runs the same static checks as CI and changes no files: Pint with
  `--test`, PHPStan, `vp check` and `tsc --noEmit`.
- `make down` keeps the volumes. Only `make fresh` deletes data (the database tables).
- `make up` waits until all services are running, and healthy when they have a health
  check.
- The `vite` service runs `npm ci` again when `package-lock.json` is newer than
  `node_modules/.package-lock.json`.
- `composer ci:check` runs inside the `app` container and must pass.

## Review Focus

1. **A fresh clone.** `make setup` in a new clone starts the stack, and a user can
   register and log in.
2. **File owner.** Files that the containers create belong to the host user.
3. **New npm packages.** After a change to `package-lock.json`, a restart of `vite`
   installs the packages again. Without a change, it does not.
4. **Hot reload.** A change in a `.tsx` file shows in the browser without a page reload.

### Task 1: Install npm packages again after a lock file change

**Files:**

- Modify: `compose.yaml`

- [ ] **Step 1: Change the command of the `vite` service**

```yaml
command: sh -c "[ node_modules/.package-lock.json -nt package-lock.json ] || npm ci; npm run dev"
```

`npm ci` writes `node_modules/.package-lock.json`. When `package-lock.json` changes
later, it is newer, and the next start runs `npm ci` again.

- [ ] **Step 2: Verify**

Run `touch package-lock.json` and `docker compose restart vite`.
Expected: the date of `node_modules/.package-lock.json` changes. A second restart does
not change it.

- [ ] **Step 3: Commit**

```bash
git add compose.yaml
git commit -m "build: reinstall npm packages when the lock file changes"
```

### Task 2: Makefile

**Files:**

- Create: `Makefile`

- [ ] **Step 1: Write `Makefile`**

The targets: `help` (the default), `setup`, `up`, `down`, `test`, `lint` and `fresh`.
`setup` copies `.env.example` to `.env` if `.env` does not exist, builds the image,
runs `composer install`, makes the app key if `.env` has no key, starts the stack, and
runs the migrations.

- [ ] **Step 2: Verify**

Run: `make`, `make up`, `make test`, `make lint`, `make fresh`.
Expected: each target ends with exit code 0.

- [ ] **Step 3: Commit**

```bash
git add Makefile
git commit -m "build: add Makefile for the local stack"
```

### Task 3: Wait for a ready stack

On a fresh clone, `vite` runs `npm ci` before it starts. Until then, the app returns
HTTP 500 ("Vite manifest not found").

**Files:**

- Modify: `compose.yaml`
- Modify: `Makefile`

- [ ] **Step 1: Add a health check to the `vite` service**

```yaml
healthcheck:
    test: [CMD, wget, -q, -O, /dev/null, http://127.0.0.1:5173/@vite/client]
    interval: 5s
    timeout: 3s
    retries: 60
```

- [ ] **Step 2: Add `--wait` to `make up`**

```makefile
$(COMPOSE) up -d --build --remove-orphans --wait
```

- [ ] **Step 3: Verify on a fresh clone**

Clone the branch into a new directory and run
`COMPOSE_PROJECT_NAME=eb-fresh make setup`.
Expected: exit code 0, `/login` returns HTTP 200, a user can register and log in, and
`vendor/` and `public/hot` belong to the host user. Then remove the test stack with
`docker compose down -v`.

- [ ] **Step 4: Commit**

```bash
git add compose.yaml Makefile
git commit -m "build: wait until the stack is ready in make up"
```
